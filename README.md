# kuis_app

Ini adalah project aplikasi kuis simpel yang dibuat pakai Android Studio. Tujuannya cuma buat nyobain bikin fitur akun dan sistem kuis dasar.

**Fitur yang ada:**
* **Bikin Akun & Login:** Fitur simpel buat daftar dan masuk ke aplikasi.
* **Menu Kuis:** Halaman awal buat milih kuis yang mau dikerjain.
* **Halaman Soal:** Tempat user ngejawab pertanyaan kuisnya sampai selesai.

**Cara jalanin project ini:**
1. Download atau clone repo ini ke laptop kamu.
2. Buka Android Studio, terus pilih **Open** dan cari folder project ini.
3. Tunggu proses *build* / *sync* Gradle sampai beres.
4. Klik tombol **Run** (segitiga hijau) di atas buat ngetes aplikasinya di emulator atau HP.
